# BCC Interactive Social Assets

Public images for BCC Interactive's social posts: posters and Instagram carousel slides. Publer pulls them from the raw file links in this repo.

Everything in this repo is public. Only finished, approved-for-public images go here. No client files, drafts, notes or source code.

## Layout

```
<week-start date, YYYY-MM-DD>/
  posters/      single images, named NN-day-topic.png
  carousels/    one folder per carousel, slides named 01.png, 02.png, ...
```

## Raw link format

```
https://raw.githubusercontent.com/bccinteractive/social-assets/main/<path>
```

The source files and the builders that make these images live in the private agency repo.
